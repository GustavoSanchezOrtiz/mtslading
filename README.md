# MTS Sistemas e Ingeniería Industrial — Landing Page

Sitio corporativo público de **MTS Ingeniería Industrial** (`ingenieriamts.com`), alineado visualmente con la identidad corporativa y tokens de diseño de **MTS Plataforma** (`administracion.ingenieriamts.com`).

## Stack

- **Vite + React 19**
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- **Lucide React**
- Fuentes corporativas locales (`Inter` y `Poppins`) y activos vectoriales oficiales MTS (`logo.svg`, `logoNegro.svg`, `DecoradorSuperIzquierdo.svg`).

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```
